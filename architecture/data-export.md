# Data export (`DataExport/`, `Settings/DataExportSettingsView.swift`)

*Part of the Emojily architecture reference. Up: [OVERVIEW.md](../../OVERVIEW.md) · Index: [§6 Features](../../OVERVIEW.md#6-features)*

---


Range picker (week / month / all time / custom) with an interactive calendar selector, mood-tape
preview, and live reflection count. **The screen is free; the export itself is premium.**
Formats: **CSV**, **JSON**, **PDF** (PDF via `PDFReportRenderer`). CSV/JSON emit comma-separated tag lists.
